# Boss 直聘岗位任职要求共性分析插件

## 功能概述

这是一个基于 Manifest V3 的 Edge 浏览器插件，用于分析 Boss 直聘岗位页面的任职要求共性。

## 主要功能

1. **自动滚动加载**：自动滚动页面加载 30+ 岗位进行统计
2. **精准关键词提取**：使用详细的词典提取具体的岗位职责和任职要求
   - 职责方向：数据仓库建设、接口开发、前端页面、算法实现、机器学习等
   - 要求方向：Java、Python、Spark、Flink、Kafka、MySQL 等具体技术栈
3. **三维统计分析**：
   - 📈 任职需求能力统计（合并职责+要求）
   - 📋 岗位职责统计（具体工作内容）
   - 🎯 任职要求统计（具体技术技能）
4. **自动清空**：切换职位类型时自动清空旧数据
5. **最小权限**：仅使用 storage 权限，无跨域请求

## 目录结构

```
boss-job-analyzer/
├── manifest.json      # 插件配置文件
├── content.js         # 内容脚本（注入页面提取数据）
├── popup.html         # 弹出面板 HTML
├── popup.css          # 弹出面板样式
└── popup.js           # 弹出面板逻辑
```

## 安装使用

### 1. 打开 Edge 浏览器
- 地址栏输入 `edge://extensions/`
- 打开左下角的"开发人员模式"开关

### 2. 加载扩展
- 点击"加载解压缩的扩展"
- 选择本项目文件夹 `boss-job-analyzer`

### 3. 使用方法
1. 打开 Boss 直聘网站 (www.zhipin.com)
2. 进入岗位搜索页面（选择职位类型、城市等筛选条件）
3. 点击浏览器工具栏的扩展图标
4. 点击"立即分析当前页"按钮
5. 插件会自动滚动加载 30+ 岗位进行统计
6. 查看三类统计柱状图和核心能力总结

## 统计维度说明

### 任职需求能力统计
合并岗位职责和任职要求的关键词，展示最热门的能力需求。

### 岗位职责统计
展示岗位要求承担的具体工作职责，如：
- 数据仓库建设、数据处理/ETL、数据分析/建模
- 接口/API开发、前端页面开发、后端服务开发
- 算法开发、机器学习/模型、大模型应用
- 架构设计、性能优化、CI/CD/DevOps

### 任职要求统计
展示岗位要求掌握的具体技术栈，如：
- Java、Python、Scala、C++ 等编程语言
- Spark、Flink、Kafka、Hive、Hadoop 等大数据技术
- MySQL、Redis、MongoDB、Elasticsearch 等数据库
- React、Vue、Spring、Django 等框架

## 技术说明

- **Manifest V3**：最新的浏览器扩展标准
- **最小权限**：仅使用 `storage` 权限
- **域名限制**：仅匹配 `*.zhipin.com/*`
- **无跨域请求**：所有数据处理在本地完成

## 注意事项

- 本插件仅在 Boss 直聘岗位列表页面（/web/geek/job）生效
- 页面结构变更可能导致提取失败，请反馈以便更新
- 数据存储在本地浏览器，清除浏览器数据将丢失分析结果
- 切换职位类型/城市/筛选条件时，旧数据会自动清空
